# NavWeb Co

NavWeb Co is a digital agency website built with PHP and Tailwind CSS.

We help businesses get seen and generate leads through modern websites and digital solutions.

---

## Tech Stack
- PHP (Core PHP, no framework)
- Tailwind CSS
- MySQL (phpMyAdmin)
- JavaScript (Vanilla)

---

## Folder Structure
- /public      → Frontend pages (index, about, contact)
- /includes    → Common layout files (header, footer)
- /assets      → Images, CSS, JS
- /admin       → Admin panel (leads, login)
- /config      → Database configuration

---

## Setup Instructions
1. Clone or upload the project to your server
2. Create a MySQL database
3. Update database credentials in `/config/database.php`
4. Import the required tables (see below)
5. Open `/public/index.php` in browser

---

## Features
- Responsive agency website
- Contact form with lead storage
- Admin panel to view leads
- SEO-friendly structure
- Tailwind-based UI
